# Impeccable Design Context — servicios_admin

## Design Context

### Users
Personal administrativo escolar: secretarias, coordinadores y personal de cobro que usan el sistema durante su jornada laboral para gestionar desayunos, estancias, ventas y reportes. El contexto es de escritorio/tablet en entorno institucional. Necesitan claridad inmediata, densidad de información manejable y cero fricción cognitiva.

### Brand Personality
**Confiable · Claro · Institucional**

El sistema debe transmitir seriedad y solidez — como una herramienta que no falla, no distrae y no sorprende negativamente. La interfaz habla por la institución.

### Aesthetic Direction
- **Referencia principal**: Vercel/Linear/Supabase — tipografía fuerte, profundidad real, micro-interacciones satisfactorias.
- **Paleta Dark**: Fondo #0f172a (slate-900), cards #1e293b (slate-800), accent indigo-500 #6366f1. Dorado #d4af37 solo para elementos de bienvenida.
- **Paleta Light**: Off-white #f8fafc, cards blancas, accent indigo-600 #4f46e5.
- **Tema**: Dark mode como base visual primaria, light mode funcional.
- **Anti-referencias**: Sin rainbow, sin neón extremo, sin glassmorphism decorativo, sin bounces elásticos exagerados, sin transition:all.

### Design Principles
1. **Claridad sobre expresión** — Cada elemento debe cumplir una función. Si no sirve, no va.
2. **Jerarquía tipográfica fuerte** — El tamaño y peso del texto guía la mirada, no los colores llamativos.
3. **Espaciado consistente** — Escala modular: 4px base, múltiplos de 4. Nada de valores arbitrarios.
4. **Color con intención** — El azul marino se usa exclusivamente para acciones primarias, estados activos y énfasis. No como decoración.
5. **Confianza institucional** — Borders sutiles, sombras pequeñas, esquinas ligeramente redondeadas. Nunca bordes cero (frío) ni radius excesivo (infantil).

### Tech Stack
- Next.js 16 + TypeScript
- CSS global (`globals.css`) — sin Tailwind
- Fuente: Geist Sans / Geist Mono (Google Fonts, cargada en layout.tsx)
- Variables CSS en `:root` para tokens de diseño
- Supabase como backend
