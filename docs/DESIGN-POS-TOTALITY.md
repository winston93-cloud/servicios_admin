- `src/app/pos/layout.tsx` — Space Grotesk + Inter, wrapper `pos-totality-theme`
- `src/app/pos/pos-totality-theme.css` — tokens y overrides scoped

## Paleta

| Rol | Color |
|-----|-------|
| Fondo obsidiana | `#121318` |
| Primary (corona / CTAs) | `#fff6df` → `#ffd700` |
| Secondary (cian etéreo) | `#bdf4ff` → `#00e3fd` |
| Tertiary (púrpura) | `#e7d1ff` |
| Texto | `#e3e1e9` / `#d0c6ab` |

Glassmorphism oscuro con glow cian/dorado en hover. El POS usa siempre este tema, independiente del dark/light del portal.
