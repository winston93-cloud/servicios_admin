# Paws & Paths — Desayunos POS

Tema visual del punto de venta (`/pos`) para personal administrativo.

## Archivos

- `src/app/pos/layout.tsx` — Plus Jakarta Sans + wrapper `pos-paws-theme`
- `src/app/pos/pos-paws-theme.css` — tokens y overrides scoped

## Paleta

| Rol | Color |
|-----|-------|
| Primary (acciones) | `#855300` → hover `#f59e0b` |
| Secondary (nav, tabla) | `#0058be` → `#2170e4` |
| Surface | `#f9f9ff` |
| Cards | `#ffffff` / `#f0f3ff` |
| Texto | `#151c27` / `#534434` |

El tema POS **siempre es claro**, independiente del dark/light del portal.
